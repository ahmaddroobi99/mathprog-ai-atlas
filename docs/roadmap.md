# Roadmap

This atlas starts as documentation. It should grow into a workbook.

## Now

- Thirteen paradigm notes with one decision each
- Ten repositories per paradigm
- One exact toy: RAG as a binary knapsack
- A documentation voice that later repos can copy

## Next

- One notebook per paradigm with a formulation you can run
- A shared coefficient schema: name, units, source model, uncertainty
- GIF style diagrams for bilevel, DRO, and min max
- A fidelity benchmark that scores prediction error, candidate loss, relaxation gap, solver gap, and execution drift separately

## Later

- Differentiable solvers as layers
- Certificates that survive batch scale
- Dynamic constraints that change after an action
- Audit traces for agentic systems: objective, constraints, provenance

## Non goals

- Replacing learned models with solvers
- Claiming every agent is a MIP
- Publishing vendor lists without a formulation
